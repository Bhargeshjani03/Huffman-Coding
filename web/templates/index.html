ABOUT THE PROJECT

Project Details

Technical overview of the model compression system.

DATA STRUCTURES & ALGORITHMS
H

Model Compression using Huffman Coding

A lossless model-weight compression system that implements Huffman coding from scratch and applies it to a trained MNIST neural network.

Dataset MNIST Handwritten digit recognition
Model Architecture 784 → 128 → 64 → 10 Fully connected neural network
Algorithm Huffman Coding Lossless entropy encoding
Container Format HUFC Custom compressed file format

Core Data Structures

Implemented as part of the project

Min Heap Efficient minimum-frequency extraction
Binary Tree Huffman tree construction
Dictionary Frequency table and codebook mapping
Bitstream Binary encoding and decoding
